# Proteus technical report

**Proteus: A Modular Framework for Agent Self-Improvement**  
The Proteus Authors · November 2026

- [Read the PDF](proteus-tech-report.pdf)
- [Browse the LaTeX source and build instructions](source/README.md)
- [Download the portable source ZIP](proteus-tech-report-source.zip)

The report explains the common method/stage/candidate/harness/evaluation contracts
and the Native reference method. It separates historical adapted task results,
bounded live harness-role pilots, and source-bound engineering checks. Implemented
compositions include ACE–Combee and GEPA–Combee. Native combinations with other
method families are reserved for a later version.

The PDF uses the authors' ICLR template typography, with a technical-report header;
it does not claim conference acceptance. The collective byline is approved for
this version; individual authors and affiliations are to be confirmed separately.

The public source bundle includes the two editable figures, bibliography, generated
tables, numeric source mappings, and pinned provenance. The larger internal review
archive and earlier manuscripts are not part of this repository publication.
Builds are offline; the optional evidence checker reads a local Proteus Git history.

The report's documentation snapshot remains `b828a85`. Current repository checks
and future release-tag gates are separate from its frozen experimental evidence.
Files here are repository documentation, not Python runtime package contents.
