## LinkedIn

We’re releasing Proteus v0.1.0, an open-source framework for evolving agent harnesses.

Proteus lets you choose a harness and model, describe an evolution objective in natural
language, and observe how the harness changes across context-fresh episodes. The objective
can be broad—make the harness more reliable—or tied to one or several concrete benchmarks.
Every trajectory remains inspectable through live measurements and versioned snapshots.

For our first public evolution experiment, we are starting from DeepSeek Harness
v0.1.0-rc.8. That release adds image input, but no first-class audio path. We’ll ask Proteus
to evolve audio attachment, persistence, transcription, and agent grounding—and stream
every completed episode on the Proteus website.

The question is deliberately simple: DeepSeek Harness just learned to see. Can it evolve
itself to hear?

Repository: https://github.com/proteus-evolve/Proteus
Install: `pip install proteus-evolve`

### 正文

Agent 的模型和能力每天都在更新，但承载 Agent 的 Harness，通常还是由人一次次手动修改。

所以我们做了 **Proteus**：一个开源的 Agent Harness 自进化框架。

你可以选择任意 **Harness × Model**，然后直接用自然语言描述它应该变成什么样：

- “让这个 Harness 更可靠”
- “优化某个具体 Benchmark”
- “同时完成多个能力目标”

接下来，Proteus 会让 Harness 在一轮轮 context-fresh episode 中检查自己、提出修改、编辑代码、运行测试并反思结果。真正参与进化的是 Harness 本身，而不只是外层 Prompt。

目前 v0.1.0 支持：

🧬 **Plug in any harness**

兼容 DeepSeek Harness、Pi，也可以接入自己的 Custom Harness。

🎯 **用自然语言设置进化目标**

可以很宽泛，也可以绑定 Benchmark；可以设置一个目标，也可以同时设置多个目标。

🔬 **把进化过程完整可视化**

每个 Episode 做了什么、修改了哪些文件、调用了哪些工具、能力分数如何变化，都可以沿着进化轨迹查看。

📸 **保留每个进化 Snapshot**

每轮进化都是一个可检查、可比较、可复用的版本，而不是只留下最终结果。

Proteus v0.1.0 现已开源：

GitHub：github.com/proteus-evolve/Proteus

整个进化 Trace 会在官网实时公开。每一轮它尝试了什么、哪里失败、如何调整、最终能不能成功，我们都会原样展示。
